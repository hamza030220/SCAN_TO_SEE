# Menu design fonts

Place licensed font files in this directory and reload the menu editor.

Supported extensions: `.ttf`, `.otf`, `.woff`, and `.woff2`.

Use a clear filename such as `My_Restaurant_Font.woff2`. The editor displays it as
`Custom My Restaurant Font`. Only letters, numbers, spaces, dots, underscores, and
hyphens are accepted in filenames.

For web performance, prefer `.woff2`. Make sure the font licence permits web use and
redistribution before committing the file.
